## 2. 数据与口径说明

这是课程作业，不是投资报告。页面把“官方披露 / 适航文件 / 媒体核验 / 教学估算”分开标注，关键边界如下：

- **X3-F 设计边界**：880 kg 最大起飞重量（专用条件适用上限 960 kg）、2 座、20 km 最大航程、20 min 最大航时、72 km/h 不可超越速度、120 m AGL、昼间目视。
- **运行限制**：私人娱乐飞行 / 飞行培训，**不用于商业载客**。不能包装成“空中出租车”或付费空中游览。
- **取证状态**：TC 进入最后阶段、TIA 已签发、69 项试验/试飞通过；TC 尚未颁发，PC/AC 未颁发。
- **交付**：2027 年中启动量产交付是公司目标，不是承诺；公司此前已确认无法在 2026 年内向终端客户交付。
- **订单**：7,000+ 为公开累计口径，含可退意向与不同时间点的定金/协议，未经审计，不能直接当收入。
- **A868**：6 座、500 km、360 km/h 为设计目标，2026-11-22 完成全倾转过渡试飞；仍是原型机，不是量产/取证状态。
- **竞品**：EHang、GOVO、Joby、Alef、PAL-V 的数据来自公开资料，口径不完全一致，只作类别参照。

## 4. 设计说明（可选，答辩时用）

- **视觉概念**：飞行试验档案 / 任务控制台。深色英雄区 + 米白报告纸 + 安全橙 + 薄荷绿，避免“科技蓝渐变”的同质化。
- **信息层级**：主张 → 证据 → 反证 → 结论。每个大数字都带口径，每个判断都带“不能支持什么”。
- **交互不是装饰**：单点失效演示对应冗余设计，场景切换对应任务包线，市场滑块对应敏感性分析，证据筛选对应来源分级。
- **课程对齐**：技术可行性、应用场景、市场可行性三问齐全；引用课程中的三条技术主线、安全挑战、产业链“纺锤形”、动力路线“纯电先行/混动主导/氢能远期”。
